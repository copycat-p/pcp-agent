개발한 프로그램을 윈도우로 옮겨서 테스트하실 때, 가볍게 파일을 전송할 수 있는 가장 쉽고 빠른 방법 3가지를 추천해 드립니다. 상황에 가장 편한 방식을 골라 쓰시면 됩니다!

### 🚀 루븐투 ➔ 윈도우 파일 전송 추천 방법                                                                                                                                                                         
                                                                                                                                                                                                                   
#### 1. Python 간단 HTTP 서버 띄우기 (가장 빠르고 일회성으로 편함)                                                                                                                                                 
                                                                                                                                                                                                                   
파이썬이 설치되어 있는 루븐투 터미널에서 전송할 파일(또는 폴더)이 있는 위치로 이동한 뒤 아래 명령어를 입력합니다:                                                                                                  
                                                                                                                                                                                                                   
```bash                                                                                                                                                                                                            
  python3 -m http.server 8000                                                                                                                                                                                      
```                                                                                                                                                                                                                
                                                                                                                                                                                                                   
- 사용법: 그 후 윈도우 PC의 웹브라우저(크롬 등) 주소창에 http://맥북에어_IP:8000을 입력하시면, 루븐투의 해당 폴더 파일들이 웹페이지로 쫙 뜹니다. 거기서 필요한 파일을 클릭만 하면 윈도우로 즉시 다운로드됩니다! (다
  끝나면 루븐투 터미널에서 Ctrl + C로 서버를 끄면 됩니다.)                                                                                                                                                         
                                                                                                                                                                                                                   
#### 2. Git을 이용한 소스코드 동기화 (개발자 정석)                                                                                                                                                                 
                                                                                                                                                                                                                   
- 개발 중이신 프로그램이 Git 저장소(GitHub 등)로 관리되고 있다면, 루븐투에서 git push 하신 뒤 윈도우에서 git pull로 받아오시는 것이 버전 관리 측면에서도 가장 깔끔합니다.                                          
                                                                                                                                                                                                                   
#### 3. 윈도우 공유 폴더 (SMB) 활용                                                                                                                                                                                
                                                                                                                                                                                                                   
- 이미 두 PC가 동일한 로컬 네트워크에 물려 있으므로, 윈도우즈의 폴더 공유 기능을 켜두시면 루븐투 파일 관리자(PCManFM 등)에서 네트워크로 바로 접속하여 파일을 드래그 앤 드롭으로 넣을 수 있습니다.                  
                                                                                                                                                                                                                   
임시로 빌드된 파일이나 테스트용 실행 파일을 빠르게 넘기실 때는 1번(파이썬 HTTP 서버) 방법이 10초 만에 세팅 가능해서 가장 편리합니다!
